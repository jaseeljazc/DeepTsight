### Project Overview

The CMS provides a secure admin panel from which the client can manage:

- Projects
- Articles
- Services
- Contact details
- Contact form enquiries
- Main website sections
- Website settings
- Draft, preview and publish controls

**Best for:** A business that wants to keep its own website content up to date without depending on a developer for routine changes.

---

## Scope of Work

The scope below is taken from the approved Software Requirements Document (SRD) for the Basic CMS. In case of any difference, the **SRD is the final reference**.

### 1. Admin Login

- Log in securely with an email address and password.
- Log out at any time.
- Multi-factor authentication (MFA) at login for extra security.
- After entering the password, a one-time verification code is required to complete the login.
- Change the password whenever required.
- Reset the password by email if forgotten.
- Only logged-in admins can open the admin panel.

### 2. Dashboard

- See an overview of all website content in one place.
- See the number of projects, articles and services.
- See which items are published and which are drafts.
- Quickly open recently added or published content.
- See the number of new contact form enquiries received.

### 3. Projects

- Add a new project with title, description, images and other details.
- Edit existing projects.
- Delete projects.
- Preview a project before publishing.
- Publish a project to make it visible on the website.
- Unpublish a project without deleting it.
- Create and manage project categories.

### 4. Articles

- Add a new article with title, image and full content.
- Write and format article text, including:
  - Headings
  - Bold text
  - Lists
  - Links
  - Images
- Edit existing articles.
- Delete articles.
- Preview an article before publishing.
- Publish an article to make it visible on the website.
- Unpublish an article without deleting it.
- Create and manage article categories.

### 5. Services

- Add a new service with title, description and icon or image.
- Edit existing services.
- Delete services.
- Turn a service on or off so it shows or hides on the website.
- Set the order in which services appear on the website.

### 6. Contact Details

- Update phone number, email address and office address.
- Update business hours, including closed days.
- Add, change or remove social media links.
- Update the Google Maps location.
- Changes update everywhere the information appears on the website.

### 7. Contact Form Enquiries

- Visitors can send messages through the website contact form.
- Every submitted message is saved and shown in the admin panel.
- View the full details of each message:
  - Name
  - Email
  - Phone
  - Subject
  - Message text
- See the date and time each message was received.
- See which messages are new and which have already been read.
- Search messages by name, email or keyword.
- Delete messages that are no longer needed.

### 8. Main Website Sections

The admin panel allows editing of the following main website sections:

- Hero
- About
- Contact

For each section:

- Change the heading and sub-heading.
- Change the body content.
- Each field has a fixed character limit (for example, up to 1000 characters for section content) so the website layout is not broken.
- A character counter is shown while typing.
- Changes appear on the website straight away.
- The design, layout and structure of these sections remain unchanged.
- Only the text inside these sections can be changed.

### 9. Website Settings

- Set the website title and description used by Google and other search engines.
- Update contact and social media information shown across the website.
- Changes take effect on the website straight away without requiring a developer.

### 10. Search and Filter

- Search projects, articles and services by keyword.
- Filter content by category.
- Filter content by draft or published status.
- Sort content by:
  - Title
  - Date
  - Display order
- Long lists are split into pages for easier browsing.

### 11. Draft and Publish

- Save content as a draft while working on it.
- Drafts are never visible to website visitors.
- Preview content before publishing.
- Publish content when ready.
- Unpublish content at any time without losing it.
- See the status of every item clearly in the list.

### 12. General

- Works in a normal web browser; nothing needs to be installed on the computer.
- Supported browsers:
  - Chrome
  - Firefox
  - Edge
  - Safari
- Best experienced on a laptop or desktop.
- Also usable on a tablet or phone.
- Login is protected.
- The site runs on HTTPS.
- Passwords are stored in encrypted form.
- Admin pages open quickly under normal use.
- Only allowed image types and sizes can be uploaded.
- The system asks for confirmation before anything is deleted.
- Hosting is set up on Vercel's free plan, including a free SSL certificate.

### 13. Technical Documentation and Handover

Full technical documentation is provided at final handover, including:

- **System overview** — technology used, project structure and how the parts work together.
- **Setup and installation details** — requirements for running the project on a new machine or server.
- **Configuration details** — environment settings, database connection and keys or services used.
- **Database structure** — tables used and how content is stored.
- **Folder and file structure** of the project.
- **Third-party services and libraries** — details of services/libraries used and where they are configured.
- **Deployment details** — how the project is put live and how updates are released.
- All login credentials, source code and editable project files handed over to the client.
- One handover session covering the documentation so that a new developer can take the project forward without depending on Codeigo.
